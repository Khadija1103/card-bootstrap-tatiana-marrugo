# Card Bootstrap - Tatiana Marrugo Jiménez

##  Descripción del proyecto

Este proyecto consiste en una **card de presentación personal** desarrollada con HTML5, CSS3 y Bootstrap 5.  
Su objetivo es aplicar conocimientos de desarrollo frontend creando un componente reutilizable para portafolios web profesionales.
